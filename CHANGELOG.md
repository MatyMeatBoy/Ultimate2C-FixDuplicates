# Changelog

## v0.1 — 2026-11-17

- Initial portable Windows release with Check, Repair, and Restore.
- Detects the known Ultimate 2C Wireless auxiliary interfaces over USB cable and the included 2.4 GHz receiver.
- Reversible device changes with state verification and rollback attempts on failure.
- English interface, documentation, MIT license, source code, and device selection tests.
- Downloadable EXE, portable ZIP, and SHA-256 checksums.
